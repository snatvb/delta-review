# File-type icons

Curated subset of file-type icons vendored from
[vscode-material-icon-theme](https://github.com/material-extensions/vscode-material-icon-theme)
(material-extensions, MIT License). Loaded via `import.meta.glob` in
[../../files/fileTypeIcons.ts](../../files/fileTypeIcons.ts); unknown extensions
fall back to a neutral lucide glyph.
